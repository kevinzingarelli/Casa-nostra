# Casa Nostra

App per progettare insieme la casa dei sogni: planimetria, materiali e stima costi in tempo reale.

Stack: Vite + React + Supabase. PWA installabile su iPhone.

## Variabili d'ambiente (da impostare su Vercel)
- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_ANON_KEY`

Le trovi su Supabase in Project Settings → API.

## Comandi
- `npm install` — installa le dipendenze
- `npm run dev` — avvio in locale
- `npm run build` — build di produzione
